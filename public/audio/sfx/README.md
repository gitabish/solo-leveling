# System Sound Effects Directory

Drop your custom sound effect audio files here:

- `popup.mp3` (or `popup.wav` / `popup.ogg` / `popup.m4a`):
  Played automatically whenever a System popup, quest alert, modal dialog, or notification appears on screen.

### Automatic Fallback
If `popup.mp3` is not present, the app automatically falls back to the built-in synthesized Web Audio sci-fi chime without showing any errors.
